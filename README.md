# Student Support Hub
### CT318 Human Computer Interaction — Group 10
**University of Galway | Academic Year 2026–2027**

## Project Overview

The Student Support Hub is an unofficial university student project developed as part of the CT318 Human Computer Interaction group design assignment.

The prototype explores how students can find clearer administrative guidance, identify appropriate university support services and understand possible next steps when dealing with registration, transfers and other student-related issues.

## Main Features

- Eight problem-based support categories
- Interactive search and issue selection
- Registration and transfer guidance
- Online and in-person support options
- Links to university information and contact pages
- Scripted live-chat demonstration
- Interactive next-step checklist
- Browser-local checklist saving and text export

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Embedded JSON
- Figma


## Important Limitations

This is an **unofficial educational prototype**, not an official University of Galway service.

- It does not access live university records or application status.
- The chat feature is simulated and does not connect to university staff.
- The prototype cannot make registration, transfer or fee decisions.
- University administrative information should be confirmed through official sources.
- Saved checklists are stored locally in the user's browser.
